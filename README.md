# POPs2 RNA-seq and eQTL analysis code

Scripts to run RNA-seq and eQTL analysis in the POPs2 pregnancy cohort. 

Pre-print: [Maternal immune gene expression trajectories and dynamic genetic regulation throughout pregnancy](https://www.medrxiv.org/content/10.64898/2026.09.22.26363644v1.article-metrics)

Data available: The RNA-Seq and genotyping datasets generated in this study are available under managed access with accession number EGAS00001006379 (will be made public upon publication). Source data for reproducing manuscript figures are available on Zenodo (10.5281/zenodo.22249714).

Interactive web portal: https://pops2.sanger.ac.uk/
